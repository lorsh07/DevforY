# DevforY

초보 개발자를 위한 **개발 언어 적성 검사** 웹사이트입니다.
11개의 간단한 질문에 답하면 관심사·학습 스타일·목표를 분석해 지금 배우기 좋은 언어와 학습 로드맵을 추천해 줍니다.

## 주요 기능

- 11문항 적성 검사 (진행률 표시, 이전 문항으로 돌아가기, 키보드 숫자키 선택)
- 12개 언어 분석: HTML, CSS, JavaScript, Python, SQL, Java, Kotlin, Swift, C#, C/C++, Go, Rust
- 결과 페이지
  - 1순위 언어와 적합도(%)
  - 이런 분께 잘 맞아요 / 만들 수 있는 것 / 관련 직업 / 입문 난이도
  - 4단계 학습 로드맵과 추천 학습 자료 링크
  - 2·3순위 언어 상세 보기, 전체 언어별 적합도 그래프
- 결과 링크 공유 (URL에 결과가 저장되어 링크를 열면 같은 결과 표시)
- 애플 스타일 디자인 (화이트 · 블랙 · 네온그린 #39FF14), 이모지 없는 타이포그래피 중심 UI
- 전체 반응형: 작은 폰(320px) · 폰 · 가로 모드 폰 · 태블릿 · 노트북 · 큰 모니터(1440px, 1920px+)
  - 노치·홈 인디케이터 안전 영역 대응, 터치 기기에서 44px 이상 터치 영역

## 실행 방법

빌드 과정이 없는 순수 HTML/CSS/JavaScript 프로젝트입니다.

```bash
# 그냥 index.html 을 브라우저로 열거나, 간단한 로컬 서버 실행
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages로 배포하려면 저장소 Settings → Pages 에서 브랜치를 선택하면 됩니다.

## 구조

```
index.html          화면 구성 (시작 / 질문 / 결과)
css/style.css       스타일
js/languages.js     언어별 소개·로드맵·학습 자료 데이터
js/questions.js     검사 문항과 보기별 점수
js/app.js           검사 진행, 채점, 결과 렌더링
```

## 채점 방식

각 보기는 여러 언어에 점수를 줍니다 (`js/questions.js`의 `scores`).
언어마다 받을 수 있는 최대 점수가 다르기 때문에, **받은 점수 ÷ 그 언어의 최대 가능 점수**로 적합도(%)를 계산해 순위를 매깁니다.
문항이나 언어를 추가하고 싶다면 `questions.js`와 `languages.js`만 수정하면 됩니다.
